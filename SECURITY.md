# Security Policy

LeadBridge and ALEMZAI treat security, confidentiality, and responsible disclosure as core requirements.

## Reporting

Do **not** open a public issue containing vulnerabilities, credentials, private URLs, customer information, authentication details, or other sensitive material.

Use the official contact channel at https://alemzai.com for security-sensitive reports.

## Public repository rules

This showcase repository must never contain production credentials, environment files, database secrets, private customer data, service-role keys, internal security logic, proprietary LeadBridge algorithms, confidential automation workflows, or unreleased commercial strategy.

If sensitive information is accidentally committed, treat the affected credential or information as exposed and respond accordingly rather than relying only on deletion from the latest commit.
